# General Tools Guide

This section covers the general-purpose utility tools available on Platzer.dev.

## QR Code Generator

Create custom QR codes for various purposes, with a special focus on WiFi network sharing.

### What is it?

The QR Code Generator allows you to create QR codes that can be scanned by smartphones and other devices. The primary feature is WiFi QR code generation, making it easy to share network credentials without typing long passwords.

### How to Use

#### Creating a WiFi QR Code

1. **Navigate to the Tool**: Select "QR Code Generator" from the Tools menu

2. **Fill in WiFi Details**:
   - **Network Name (SSID)**: Enter your WiFi network name
   - **Password**: Enter your WiFi password
   - **Encryption Type**: Select your network's security type:
     - **WPA/WPA2**: Most common for modern networks (recommended)
     - **WEP**: Older encryption method (less secure)
     - **None**: For open networks without passwords
   - **Hidden Network**: Check this box if your network SSID is hidden

3. **Generate QR Code**: Click the submit/generate button

4. **Use the QR Code**:
   - Display it on your screen for guests to scan
   - Download or screenshot it for printing
   - Share it digitally with others

### Scanning the QR Code

#### For Guests/Users:
1. Open your phone's camera app (most modern phones support QR scanning natively)
2. Point the camera at the QR code
3. Tap the notification that appears
4. Your device will automatically connect to the WiFi network

#### Compatible Devices:
- **iOS**: iPhone (iOS 11+) with Camera app
- **Android**: Most Android phones (Android 10+) with Camera app
- **Alternative**: Use any QR code reader app from the app store

### Security Tips

1. **Use WPA/WPA2 Encryption**: Always use the strongest encryption available
2. **Separate Guest Networks**: Consider creating a separate guest network for visitors
3. **Regular Password Changes**: Update your WiFi password periodically and regenerate the QR code
4. **Control Distribution**: Be mindful of where you post or share your WiFi QR codes
5. **Monitor Connected Devices**: Regularly check which devices are connected to your network

### Best Practices

- **Clear Display**: Make sure the QR code is large enough to scan easily (at least 2-3 inches if printed)
- **Good Lighting**: Place printed QR codes in well-lit areas
- **Test First**: Always test the QR code before distributing it widely
- **Include Instructions**: For less tech-savvy users, add simple scanning instructions near the code
- **Backup Method**: Always have the password written down as a backup

### Troubleshooting

#### QR Code Won't Scan
- Ensure good lighting
- Hold camera steady and at the right distance
- Make sure the QR code is not damaged or distorted
- Try a dedicated QR reader app if native camera doesn't work

#### Device Won't Connect
- Verify the WiFi information is correct
- Check that encryption type matches your router settings
- Ensure WiFi is turned on and in range
- Try entering credentials manually as a backup

#### Wrong Information Entered
- Simply regenerate a new QR code with the correct information
- Delete or destroy old QR codes to avoid confusion
