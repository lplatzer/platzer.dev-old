# Platzer.dev User Guide

Welcome to Platzer.dev! This website offers a collection of tools designed to bridge the world of software development and coffee culture.

## About

Platzer.dev is created by Luis Platzer, a software developer, former professional barista, coffee roaster, and coffee enthusiast. The goal is to provide useful tools that help you enjoy and improve every cup of coffee, along with other handy utilities.

## Getting Started

### Accessing the Website

Simply navigate to the website URL in your browser. No registration or login is required for most features.

### Navigation

The website uses a simple navigation menu:
- **Home**: Learn about the creator and the mission
- **ETF Tracker**: Track and analyze ETF (Exchange-Traded Fund) performance
- **Coffee Tools**: Access various coffee-related utilities
- **Tools**: General-purpose utilities
